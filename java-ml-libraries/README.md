Source code for the article https://howtodoinjava.com/ai/java-machine-learning-libraries/

Trains the same apple/banana logistic regression classifier with Smile and with Tribuo.

Versions: Java 25, Maven 3.9, Smile 6.3.0, Tribuo 4.3.2

Run:

    mvn compile
    mvn exec:java -Dexec.mainClass=com.howtodoinjava.ml.SmileExample
    mvn exec:java -Dexec.mainClass=com.howtodoinjava.ml.TribuoExample
